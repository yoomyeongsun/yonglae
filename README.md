# 강릉시 자원순환센터 손수건 기념품 디자인 보고 (웹 보고서)

## 폴더 구성
- index.html : 보고서 본문 (모든 화면·애니메이션·색상 시연 기능 포함)
- assets/    : 손수건 이미지, 활용 사진

## Vercel 배포 (가장 쉬운 방법)
1. GitHub에서 새 저장소(예: gangneung-handkerchief)를 만든다
2. 이 폴더 안의 파일을 모두 끌어다 놓아 업로드(Commit)한다
3. vercel.com → Add New → Project → 방금 만든 저장소 선택 → Deploy
4. 발급된 주소(https://○○.vercel.app)를 발표 PC·휴대폰에서 연다

## 발표 팁
- 오른쪽 위 「발표 모드」: 전체 화면
- 키보드 ← → 또는 PageUp/PageDown: 장 단위 이동
- 「색상 시연」: 손수건에서 바꿀 색 찍기 → 색상표에서 원하는 색 찍기
